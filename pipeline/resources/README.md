# Pipeline resources

Static reference files used by the pipeline rules.
These files are **not** generated by Snakemake — they must be present before running.

## hg19_genes.bed

hg19 RefSeq gene coordinates in BED6 format, derived from the UCSC refFlat table.
Used by `task2_gene_region` for `bedtools intersect` annotation.

**Columns:** chrom, txStart, txEnd, geneName, ".", strand

**To regenerate:**
```bash
wget -qO- http://hgdownload.soe.ucsc.edu/goldenPath/hg19/database/refFlat.txt.gz \
    | gunzip \
    | awk 'BEGIN{OFS="\t"} {print $3, $5, $6, $1, ".", $4}' \
    | sort -k1,1 -k2,2n \
    > pipeline/resources/hg19_genes.bed
```

**Source:** UCSC Genome Browser, hg19 refFlat table
**Size:** ~81,000 transcript-level intervals (~3 MB)
